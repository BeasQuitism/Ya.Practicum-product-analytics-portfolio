### ⚙️ Оркестрация пайплайнов данных с помощью Apache Airflow и PySpark (Сервис Яндекс Книги)

**Задача:** Автоматизировать процесс обработки и агрегации данных о пользовательской активности в сервисе чтения и прослушивания книг, создав надежный ETL-пайплайн для формирования аналитических витрин.

**Что сделал:**
- Написал PySpark-скрипт для обработки сырых данных: чтение из S3, агрегация по пользователям (подсчет количества сессий и среднего времени прослушивания/чтения) и выгрузка результатов в аналитическую СУБД ClickHouse через JDBC.
- Спроектировал и реализовал DAG в Apache Airflow с ежедневным расписанием (`@daily`).
- Настроил сенсор `S3KeySensor` для контроля появления входных данных в хранилище (проверка каждые 5 минут, таймаут 1 час).
- Интегрировал задачу запуска Spark-кода на облачном кластере Yandex Cloud Dataproc с помощью оператора `DataprocCreatePysparkJobOperator`.
- Выстроил корректные зависимости между задачами (ожидание данных → запуск обработки).

**Результаты:**
- Создан полностью автоматизированный ETL-пайплайн, который ежедневно формирует витрины данных без ручного вмешательства.
- Обеспечена отказоустойчивость пайплайна за счет сенсора, который предотвращает запуск обработки до появления актуальных данных в S3.
- Настроена бесшовная интеграция между облачным хранилищем (S3), вычислительным кластером (Dataproc) и аналитической базой (ClickHouse).

**Инструменты:** Apache Airflow, PySpark, Yandex Cloud Dataproc, S3, ClickHouse, Python, JDBC.

📁 **Файл:** `Airflow. Оркестрация пайплайнов.ipynb`
