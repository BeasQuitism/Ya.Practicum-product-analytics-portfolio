### 🚖 Автоматизация ETL-пайплайна для Яндекс Такси (PySpark + Airflow + ClickHouse)

**Задача:** Построить автоматизированный пайплайн обработки данных для Яндекс Такси, который будет ежедневно агрегировать миллионы записей о поездках по способам оплаты и загружать результаты в аналитическую базу данных для финансовых и продуктовых команд.

**Что сделал:**
- Написал PySpark-скрипт для чтения данных из Parquet-файлов в S3, агрегации поездок по типам платежей и выгрузки итоговой витрины в ClickHouse через JDBC.
- Спроектировал и настроил DAG в Apache Airflow с ежедневным расписанием (`@daily`).
- Использовал `S3KeySensor` для контроля появления нового файла с данными в S3-хранилище перед запуском обработки.
- Интегрировал запуск Spark-кода на облачном кластере Yandex Cloud Dataproc с помощью `DataprocCreatePysparkJobOperator`.
- Выстроил корректные зависимости между задачами (ожидание данных → запуск агрегации на кластере).

**Результаты:**
- ✅ Создан полностью автоматизированный и отказоустойчивый ETL-пайплайн, который ежедневно обрабатывает большие объемы данных без ручного вмешательства.
- ✅ Обеспечена целостность данных за счет сенсора, который предотвращает запуск пайплайна до появления актуального Parquet-файла.
- ✅ Агрегированные данные о выручке и способах оплаты автоматически попадают в ClickHouse (`taxi_payment_summary`), что позволяет бизнес-командам быстро строить отчеты.

**Инструменты:** Apache Airflow, PySpark, Yandex Cloud Dataproc, S3, ClickHouse, Python, JDBC, Parquet.
