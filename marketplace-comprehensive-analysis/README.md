### Комплексная оценка состояния маркетплейса: A/B-тестирование и анализ маркетинга

**Задача:** Провести комплексный анализ здоровья продукта на примере маркетплейса: оценить результаты A/B-теста новой фичи, проанализировать пользовательские воронки и эффективность распределения маркетингового бюджета по каналам.

**Что сделал:**
- **Анализ A/B-теста:** Сравнил динамику регистраций и пользовательской активности между контрольной (`control`) и тестовой (`treatment`) группами за 25-дневный период.
- **Воронки событий:** Проанализировал ключевые этапы пользовательского пути (`page_view` → `product_view` → регистрация/покупка) для выявления узких мест в онбординге.
- **Оценка маркетинговых каналов:** Сопоставил данные о маркетинговых затратах (`budget` по месяцам и каналам) с количеством привлеченных пользователей для оценки эффективности расходов.
- **Визуализация:** Построил графики динамики регистраций по дням в разрезе групп A/B-теста и визуализировал распределение маркетингового бюджета.

**Результаты:**
- ✅ Оценил статистическую значимость влияния изменений в продукте на ключевую метрику (конверсию в регистрацию).
- ✅ Выявил сезонные или недельные паттерны в поведении пользователей, что помогает в планировании маркетинговых активностей.
- ✅ Сформулировал рекомендации для продуктовой команды (по улучшению воронки на основе A/B-теста) и для маркетинга (по оптимизации распределения бюджета между каналами).

**Инструменты:** Python (pandas, matplotlib, seaborn, scipy), статистический анализ, когортный подход, анализ воронок.
